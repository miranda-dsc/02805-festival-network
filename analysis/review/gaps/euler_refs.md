**Clashfinder collection.** On 25 November 2026, the live robots file returned HTTP 200 and declared a 10-second crawl delay under the wildcard group. It allows the event JSON path. The public API docs describe authentication and JSON but give no separate request interval. The top-level download loop in `src/00_download_clashfinder.py` shows one authenticated request at a time with a project User-Agent, cached files skipped, and a two-second sleep after each response. That pause is shorter than the published crawler guidance. I found no collection-run timestamps that establish the actual request spacing or the guidance in effect on the collection date.
